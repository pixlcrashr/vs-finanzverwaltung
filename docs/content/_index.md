# VS-Finanzverwaltung

VSFV ist ein Finanzverwaltungssystem fuer Verfasste Studierendenschaften. Es bietet Haushaltsplanung, Transaktionsverwaltung mit doppelter Buchfuehrung und umfassende Berichtsfunktionen.
